🪙 Coin Scout V6 — Visual + Date Reader

Generic visual model for coin type + browser OCR model for the date. No OpenAI API.
Date reader uses this side first.
Useful for type and mint evidence.
V6 change

The previous versions used CLIP to guess the year indirectly. That is the wrong job for CLIP. V6 adds TrOCR-small-printed, a browser OCR model, and gives it several enlarged, contrast-enhanced crops of the obverse date area. The visual model remains responsible for coin family/type.

A raised/engraved coin date is harder than normal printed text, so V6 may still fail on a blurry or worn photograph. If it does, it will show the OCR output instead of inventing a year.
