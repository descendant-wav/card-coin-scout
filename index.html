🚦 How to use V11.4
  1. Photograph the coin. Scout gives denomination suggestions, but never changes the denomination for you.
  2. Tap the correct denomination. Scout then narrows the type within that denomination only.
  3. Read the year and mint yourself. Early Jefferson dates such as 1938, 1939 and 1950-D get extra scrutiny. Use Set Aside for anything you want to research later.
  4. Run SCREEN FOR TREASURE.
  5. COMMON → move on. MELT → keep. CHECK → hold. HOT → isolate and research.
Rule: a rare date/error result is a stop sign, not a price guarantee. Authenticate important coins before selling.
