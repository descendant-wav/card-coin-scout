🚦 How to use V12.5 — Coin-Located OCR + Android Photo Fix Edition
  1. Photograph the coin close and sharp. Scout gives design suggestions, but never changes the denomination for you.
  2. Tap the correct denomination.
  3. Tap READ YEAR + MINT. Scout finds the coin in the photo, then uses local browser OCR on focused date/mint regions. Correct anything it gets wrong.
  4. Run SCREEN FOR TREASURE.
  5. COMMON → move on. MELT → keep. CHECK → hold. HOT → isolate and research.
Rule: a rare date/error result is a stop sign, not a price guarantee. Authenticate important coins before selling.
