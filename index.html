🪙 Coin Scout V3 — Visual + Evidence

Browser vision + local U.S. coin rules. No OpenAI API key.
What V3 is doing
  • Visual model: identifies the coin family/type from the actual photo.
  • Year evidence: runs several local OCR passes against the obverse and looks specifically for 4-digit U.S. years.
  • Era cross-check: once the visual type is known, it checks likely historical eras for that series.
  • Local treasure screen: silver, key dates, major varieties and obvious error candidates are handled without API calls.
The visual model downloads once into the browser cache. It can be slow on the first run.
