🪙 Coin Scout V2 — Visual Scout

Actual browser-based vision model. No OpenAI API key.
How this version works
  • The photo is sent to a vision model that runs inside the browser.
  • It proposes likely coin types from the actual image.
  • It does not pretend it can reliably read every year or mint mark.
  • Once you confirm the year/type, the local U.S. rules calculate silver and treasure triage.
The first visual-model run can take a while because the model has to download into the browser cache. Later runs should be faster.
